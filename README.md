# 🐍 Python DSA

## 📚 Topics Covered

### Data Structures
- Arrays
- Strings
- Stack
- Queue
- Linked List
- Hashing
- Trees
- Heap
- Graphs

### Algorithms
- Searching
- Sorting
- Recursion
- Backtracking
- Greedy Algorithms
- Dynamic Programming
- Graph Algorithms
